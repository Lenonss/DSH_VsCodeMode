# dsh-vscode-mode 0.14.9

## 编辑快捷键

- `Ctrl+/` 保留 DSH 官方快捷键入口，不再在插件编辑器内触发行注释。
- `Ctrl+Alt+/` 切换行注释，通过官方快捷键目录注册，仅在插件代码输入区触发；Web Linux 受官方白名单限制，默认不绑定，可从命令栏或编辑器右键菜单执行。
- `Ctrl+D` 为编辑器本地的向下复制行快捷键，调用 Monaco 原生 `editor.action.copyLinesDownAction`，不注册页面级默认键位。只读编辑器不执行；不自行实现撤销、多光标或选区算法。
- 块注释 `Ctrl+Shift+/` 不变。macOS 对应主修饰键为 Cmd。

## 桌面安全刷新

桌面默认 `Ctrl+Shift+R`，Web 默认不绑定；命令栏提供「刷新当前界面（不重启 Host）」。这只是当前页面刷新，不是完整桌面应用或 Host 重启。

刷新前检查所有挂载编辑器：未保存代码或 PDF、自动保存待执行、保存进行中、外部文件冲突均拒绝刷新。只捕获编辑视图状态，不主动保存或丢弃文件内容；严格等待界面状态镜像落盘并再次检查安全状态，失败或超时不刷新。请求串行执行，卸载时取消后续刷新。模态窗口打开时不触发。

## 验证边界

已完成 9 个专项测试文件共 142 个用例、TypeScript 类型检查和双面构建。发布准备另执行完整项目 JS 发布套件（Vitest 与 nativeOpen Node 测试）；具体结果记录在发布报告。

**未验证**：真实 Web/桌面 GUI 的实际按键、撤销与多光标行为、核心编辑入口、只读/模态回退、Console 与刷新后的状态恢复。用户已明确接受此 GUI 验收缺口，不以模拟测试替代真实 GUI 证据。

## 安装与回退

固定安装版本为 `dsh-vscode-mode@0.14.9` 或 Git tag `v0.14.9`。完整安装后需重启目标 Host 并刷新原页面；本次公开发布不自动修改任何 DSH profile 或重启应用。此前客户端局部部署不等同于完整安装 0.14.9。

依赖与 DSH 兼容范围未变，仍精确支持此前已声明的 0.2.0-rc.1/rc.2，不扩展至其他 0.2 版本。无新增数据格式迁移；从 0.14.2 或更旧版本升级仍需参阅 [0.14.3 数据迁移与回退说明](release-0.14.3.md)。公开 tag 和版本保持不可变；出现发布问题不覆盖历史版本、不重跑已尝试 publish 的发布任务。
