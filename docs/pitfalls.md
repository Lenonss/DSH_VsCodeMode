# 工程坑位清单（本插件视角）

> 加新功能前先扫一遍；每条都给「现象 / 根因 / 定案 / 回归」。踩过一次就写进来，别靠记忆。
>
> 部分条目来自公开同类插件（如 [dsh-gufa-code](https://github.com/liujiangnanchenjbguo/dsh-gufa-code) 的
> Known-Pitfalls）的**经验教训**，本文为对照本插件架构重写，不是源码移植。

## 1. Monaco 自定义协议下 worker 与语言注册

- **现象**：差异视图永远没有红绿；新加的模板语言打开后仍是纯文本。
- **根因**：① 页面源是 `dsh-app://` / 自定义协议时，Monaco 默认 blob worker 里的相对
  `importScripts` 不是合法 URL；② `createModel` 只认 `monaco.languages.getLanguages()` 里
  **已存在**的 id，语言注册晚于模型创建就静默回落 plaintext（不报错）。
- **定案**：worker 以同源静态入口引导（`MonacoEnvironment.baseUrl` + `importScripts`），
  不先加载 AMD `loader.js`；模板语言注册放在 `editor.main` 回调内、`resolve(monaco)` 之前。
- **回归**：`tests/templateLanguages.test.ts`（状态引用完整、注册幂等）+ 真机打开
  `.ejs/.njk/.blade.php` 看状态栏语言 id。

## 2. 语言映射「写错 id 不报错」

- **现象**：某些后缀的文件就是没有分色，日志里什么都没有。
- **根因**：`langOf` 的返回值不是 `getLanguages()` 里的 id 时，Monaco 不抛错、只按无语言处理。
- **定案**：`tests/langMap.test.ts` 直接解析随包 `editor.main.js` 的语言贡献表做机器审计：
  映射值必须存在、自定义 id 不得与内置冲突、覆盖官方映射必须登记。
- **回归**：改 `LANG_BY_EXT` 后跑该测试；升级 Monaco 时失败信息会列出差集。

## 3. 破坏性写盘前必须落盘

- **现象**：跨文件替换后，用户刚敲的几行改动「消失」了。
- **根因**：编辑器缓冲有 700ms 防抖保存；替换读磁盘 → 拿到旧内容 → 写回时把未保存编辑覆盖掉。
- **定案**：写盘前广播 `edrv:flush-all`，每个挂载中的 `EditorView` 注册「提交全部待保存」的
  promise，等待完成（3s 上限）；超时即中止替换并提示手动保存。
- **回归**：脏页签 → 全部替换 → 用户改动仍在（`docStores.flush` 已落盘）。

## 4. 替换的版本守卫与逐文件失败

- **现象**：批量替换里某个文件刚好被 agent/其他编辑器写了，整批失败或悄悄覆盖。
- **根因**：读-改-写之间没有版本校验。
- **定案**：逐文件 `fs.writeText(..., { kind: 'replaceIfVersion', version })`；冲突记为该文件
  `failed` 并继续处理后面的文件；结果里逐条给出原因。
- **回归**：`tests/replacePlan.test.ts` 的失败原因映射 + 真机并发编辑场景。

## 5. 空匹配正则会毁文件

- **现象**：用 `a*` 这类正则替换，文本每个字符之间都被插入替换串。
- **根因**：零宽匹配在每个位置都成功。
- **定案**：`compileReplace` 对 `'' / 单字符 / 多字符 / 空白 / 换行` 探测，命中空串直接抛错拒绝。
- **回归**：`tests/replacePlan.test.ts`「拒绝会匹配空串的模式」。

## 6. 复制拦截不能吞掉普通复制

- **现象**：想复制一小段代码贴到别处，结果剪贴板成了 `@a.ts L3-L5`。
- **根因**：把所有选区都当引用。
- **定案**：跨行选区才算引用；单行只有**整行选中**才算（`selectionRange`）；只在编辑器根节点内
  拦截；`refIntake` 关闭时完全走原生复制。
- **回归**：`tests/refSyntax.test.ts`（半行/整行/空行）+ 真机「复制单行中间几个词」粘贴验证。

## 7. 事件回调里的 preventDefault 必须同步

- **现象**：粘贴/拖拽后既插入了引用，浏览器又执行了默认行为（把文件当页面打开 / 重复插入）。
- **根因**：`preventDefault()` 在 await 之后调用已经太晚。
- **定案**：回调里只用 payload 形态做同步判断（自定义 MIME / `@` 开头文本 / 非图片文件），
  确认接管就立即 `preventDefault` + `stopPropagation`，再异步解析路径；解析失败回退纯文本。
- **回归**：`tests/refIntake.test.ts`（拖拽/粘贴意图判定）。

## 8. 多实例监听会重复插入

- **现象**：编辑器在侧栏和浮窗各挂一份时，一次粘贴插入两条引用。
- **根因**：每个 `EditorView` 都挂了 document 级监听。
- **定案**：`refIntake` 维护 owner 栈，只有最后挂载的实例处理事件；卸载时出栈。
- **回归**：真机「侧栏 + 浮窗同时打开，粘贴一次只出现一条引用」。

## 9. 拖拽分割条不要每帧 setState

- **现象**：拖侧栏宽度或终端高度时明显发涩，编辑器内容跟着抖。
- **根因**：`mousemove` 每帧写 React 状态 → 整棵树（含 Monaco 容器）重渲染。
- **定案**：拖动中只写根节点 CSS 变量（rAF 合帧，不触发 React），松手时一次性提交并持久化；
  组件尺寸统一走 `var(--edrv-*, 数值px)`。
- **回归**：拖动时用性能面板看无 React commit；松手后宽度落盘。

## 10. 外部改动绝不覆盖脏缓冲

- **现象**：AI/其他工具改了磁盘文件，用户正在编辑的未保存内容被覆盖。
- **根因**：同步逻辑无条件 `setValue`。
- **定案**：版本令牌变化后**再比内容**；内容不同且缓冲干净才自动刷新，脏缓冲只提示三选一；
  保存带回上次读取的版本做 `replaceIfVersion` 守卫。参见 README「外部改动自动同步」。
- **回归**：外部写盘 + 未保存编辑 → 只出现提示条，内容不丢。

## 11. 浮层层级与主题变量

- **现象**：弹窗被右侧会话/浮窗盖住一半，或 portal 出来的弹窗背景透明、像蒙了一层膜。
- **根因**：① 插件根节点有独立层叠上下文，内部 z-index 再大也出不去；② portal 到 body 后
  拿不到根节点上定义的主题变量。
- **定案**：弹层统一用既有 `ModalShell`（portal 到 body、坐标/层级集中在组件内），
  层级只按 `tests/overlayZOrder.test.ts` 的阶梯取值；portal 宿主补一套完整主题变量。
- **回归**：`tests/overlayScope.test.ts` / `overlayZOrder.test.ts` + 真机逐个弹窗点一遍。

## 12. 模板/点文件的双扩展名与大小写

- **现象**：`welcome.blade.php` 高亮成 PHP；`Index.NJK` 没有分色。
- **根因**：只取最后一个点，且大小写敏感。
- **定案**：`langOf` 先查点文件名、再查复合后缀（`.blade.php`、`.d.ts`）、再取末段扩展名，
  全程小写归一；`tests/langMap.test.ts` 覆盖大小写与分隔符。
- **回归**：上述测试 + 真机打开大写扩展名文件。

## 13. 文本读通道会吃掉 BOM

- **现象**：替换一个带 UTF-8 BOM 的文件后，BOM 消失（`od -c` 首三字节 `357 273 277` 不见），
  对依赖 BOM 识别编码的脚本/工具是破坏性改动。
- **根因**：`fs.readText` 解码时剥掉 BOM；替换后把「无 BOM 的文本」写回，等于顺手删了 BOM。
  单测里手写带 BOM 的字符串永远通过，掩盖了这条通道差异（真机验收才发现）。
- **定案**：写回前用 `fs.readBytes` 读原始字节判断 BOM（`isBom`），读文本没有 BOM 前缀就补回去；
  `readBytes` 缺失/失败时退化为「文本自带 BOM 才保留」，不阻塞替换。
- **回归**：`tests/replacePlan.test.ts` 的 `isBom` 用例 + 真机 `bom.txt` 替换后 `od -c` 校验。

## 14. 文件名检索不能「挑一个最近的」就插

- **现象**：粘贴一个在多个目录同名的文件（如 `index.ts`），引用被静默插成 `src/index.ts`，
  用户以为引用的是另一个文件。
- **根因**：候选排序后直接取第一名，只在「完全同分」时才提示多义；路径更短的那个永远赢。
- **定案**：只有在「唯一候选」或「活动文件所在目录恰好只有一个同名候选」时才自动插入；
  其余情况返回候选让调用方提示、不插（`ambiguityOf`）。
- **回归**：`tests/refPointer.test.ts` 的五种多义组合 + 真机粘贴同名文件不插 chip。
