# v0.21.2 — 新版 DSH 会话与 MCP 适配

## 变更

- 新版会话任务发送使用公开 Session Controller：持有固定目标的生命周期，完成、失败或插件卸载后释放；受理状态不明时不改换传输重发，避免重复任务或重复建会话。
- 草稿引用通过可用的公开 binding 取得上下文，并保留旧 Host 能力回退。
- 文件范围引用在模型文本、剪贴板与纯文本降级中统一保留行区间；含空格路径保持路径引号与范围边界。
- 项目 MCP 发现优先读取公开 `definitions`，旧 Host 保留 `view` 回退；目录缺失时安全失败，不暴露未过滤工具，执行权限仍由官方执行器决定。
- MCP 初始化失败接入现有持久化诊断通道，记录阶段、传输类型、耗时与有界错误原因链；移除已知配置凭据与 URL，不将原始配置写入状态响应。
- 官方集成测试迁移到 native/PTC 执行器和批量调用契约，保留作用域隔离、拒绝、共享连接、下一请求发布工具与卸载语义断言；可显式启用真实 CodeGraph stdio 回归。

## 验证与已知边界

- 本轮适配定向验证：类型检查通过，131 项测试通过；完整发布套件与 CI 结果以对应 Release 工作流为准。
- 当前本地 Web GUI 已完成加载验证；当前运行 Host 已完成 CodeGraph 发现、连接、发布 4 个工具及真实 `codegraph_search` 调用。
- 首次连接曾在 `starting` 阶段等待约 60 秒后超时；显式重新装配后，恢复原始配置也可成功。根因未证实，本版不宣称彻底修复偶发超时。
- 未向真实 AI 会话发送测试任务；Session Controller 的发送与取消路径由定向测试覆盖，不把它表述为真实模型任务验收。
- 保留历史版本的 XLSX、官方差异导航和缺失文件审查等既有功能及验收边界；本版不增加其已验证范围。

## 升级

使用插件管理器或安装 `dsh-vscode-mode@0.21.2`；替换包后重启目标 DSH Host 并强制刷新页面。

本次发布不自动安装至任何 profile，不修改用户 MCP 配置，也不重启正在运行的 DSH。依赖、存储格式与历史数据迁移规则未改变。
