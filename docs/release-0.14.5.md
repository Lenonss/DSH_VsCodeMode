# dsh-vscode-mode 0.14.5 发布说明

> 2026-10-09；基线 v0.14.4。计划模式接入与行内差异显示修复。没有新增 npm 依赖、Host RPC、数据迁移或扩大 DSH 兼容版本范围。

## 改动

- 工作区 `plans/`、DSH `.dsh/plans/` 中的 Markdown 计划文件默认预览；成功写入以 `# 计划：` / `# 计划:` 开头的 Markdown 可建立当前会话关联。显式行号链接仍进入源码定位，普通 Markdown 的既有方式不变。
- 自动打开只消费当前会话的实时事件增量，成功写入/修改计划文件后打开预览；完整计划提交可在等待审批时展示。刷新、历史翻页、重连、切换会话和重复事件不会重播历史计划。旧版缺少 Session 事件源时不启用自动生成检测。
- 官方计划资源与待审批计划可以转入编辑器只读虚拟页签，最多保留 32 份；正文仅保存在当前编辑器内存，不写磁盘，不接入保存、LSP 或 SVN。打开回执要求会话、内容和实际计划容器匹配；切换会话或卸载取消待处理请求。失败保留官方查看器回退入口，审批仍使用对话中的官方控件。
- 行内增删和 Monaco diff 共用独立明暗色盘，移除删除代码的统一红字、边框与阴影。配色是明确的回落色盘，不宣称为经过官方令牌核验的精确色值。
- 删除代码按当前模型语言整块调用 Monaco 着色，并跟随字体、行高和边栏布局。着色失败保留安全纯文本；模型、语言、主题或生命周期变化后拒绝过期异步结果。删除正文和旧行号使用 Monaco view zone / margin 节点，不再依赖手写滚动覆盖层；释放区域、装饰和监听。
- 旧行号来自可反向验证的执行后快照和原指纹/精确坐标，缺少证据时显示占位，不把当前行号冒充原行号。修复 BOM/CRLF 文本中纯删除的归一化坐标和空新增行；快照改变后不复用可能错位的删除点。补充 1 MiB / 200 hunk 快照路径性能样本。

## 升级与回退

确认产物可用后，从 `v0.14.5` Git tag、GitHub Release tgz 或 `dsh-vscode-mode@0.14.5` 安装到实际目标 profile；Desktop 使用其专属插件安装入口，不套用 Web 示例目录。本次公开发布不自动替换用户本地包、修改 profile 或重启进程。

本版功能改动在 Client；替换插件包后建议重启目标 DSH Host 并强制刷新原页面，确保实际加载新的客户端与 CSS。热重载不能代替 CSS 整页刷新。验证计划页签前应确认当前运行版本，而非只看磁盘版本号。

回退到 v0.14.4 会失去本版计划接入和差异显示修复；本版没有新的数据迁移。从 0.14.2 或更旧版本升级或回退，仍须遵循 [0.14.3 数据迁移与回退说明](release-0.14.3.md)，不要删除 SQLite 新库或用旧 JSON 覆盖当前数据。虚拟计划正文不是磁盘文件，退出编辑器后不持久化，审批记录仍由 DSH 管理。

发布仅由 Git tag 触发既有 GitHub Actions；本机不执行 `npm publish`。实际上线状态以 Actions 最终结果、Release asset 与 npm 注册表读回为准。
