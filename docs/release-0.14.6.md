# dsh-vscode-mode 0.14.6 发布说明

> 2026-10-09；基线 v0.14.5。同工作区切换对话保留编辑器位置，跨文件共享 Ctrl+F 状态。没有新增 npm 依赖、Host RPC、数据迁移或扩大 DSH 兼容版本范围。

## 改动

- Monaco host 卸载时，在释放编辑器及清空引用前保存视图状态，避免切换对话后回到第一行。状态属于实际绑定的工作区、文件和模型，不依赖已经变化的 React `active` / `scope` 闭包。
- 按文件保存滚动、光标、选区与 Monaco 可恢复的折叠状态；模型重新绑定时恢复，同一模型的普通重渲染不重复恢复旧快照。显式行号导航在恢复后执行，仍具有优先级。Markdown 源码与预览切换沿用同一释放/恢复流程。
- 同工作区跨文件及编辑器重挂载共享 Ctrl+F 的查询、大小写、全词、正则与显示/关闭状态，不共享选区搜索范围、当前匹配序号或替换内容。查找仍只作用于当前文件，不改变 Ctrl+Shift+F 工作区搜索。
- 恢复查找状态不从新文件选区或剪贴板重设查询，不主动抢焦点或跳到首个匹配。不同工作区隔离；卸载释放监听。Monaco 内部查找贡献不可用时保留原生查找降级，不阻断编辑器。
- 视图状态继续使用现有有界持久化缓存；查找共享状态仅保存于当前客户端模块内存，不承诺跨页面刷新或 DSH 重启恢复。

## 验证范围与边界

- 本次修复的最小回归范围为 5 个文件：`editorViewState`、`editorFindState`、`viewStateCache`、`modelCache`、`scopeStore`，49/49 通过；包含释放前捕获、仅滚动后重挂载、多文件不同位置、作用域切换、不重复恢复、显式定位优先、预览往返、查找开关/选项共享及监听清理等替身测试。
- 发布门禁在实际暂存树按顺序执行 `pnpm typecheck` → `pnpm test`（完整 Vitest 与 nativeOpen JS 发布套件）→ `pnpm build`（Host / Client 双入口）；公开状态另由 GitHub Actions、npm 版本/latest/gitHead 与实包完整性、入口核验确定。发布会话记录保存完整退出码、计数、耗时及构建提示。
- 自动化测试使用生命周期/Monaco 替身，不代替真实浏览器渲染验收。本会话没有浏览器调试工具，**尚未完成真实 GUI、Console、主题/折叠与切换交互验收**；用户已明确接受该发布缺口。加载发布包后应现场复核：文件滚动到中间 → 切换同工作区对话；A 文件设置 Ctrl+F → 切至 B；关闭查找、切工作区及显式行号跳转。
- 未执行 Linux/macOS 现场验收或 Unity Editor 测试。DSH 兼容范围与 v0.14.5 相同：已声明的 0.1.x 和精确放行的 0.2.0-rc.1 / rc.2，不包含其他未经适配的 0.2 版本。

## 升级与回退

确认产物可查询后，从 `v0.14.6` Git tag、GitHub Release tgz 或 `dsh-vscode-mode@0.14.6` 安装到实际目标 profile。Desktop 使用其专属安装入口，不套用 Web 示例目录。本次公开发布不自动替换当前本地包、修改 profile、刷新页面或重启 DSH；此前单独批准的本地部署与此次公开发布分别记录。

本版源码功能改动仅在 Client；替换包后仍应确认当前 Host / Client 的实际加载版本，必要时由用户重启目标 DSH Host 并强制刷新原页面，不把安装完成当作 GUI 生效证据。

回退到 v0.14.5 会失去本次位置保持与共享查找修复，没有新增数据迁移。从 0.14.2 或更旧版本升级或回退，继续遵循 [0.14.3 数据迁移与回退说明](release-0.14.3.md)，不要删除 SQLite 新库或用旧 JSON 覆盖当前数据。

发布仅由新 Git tag 触发现有 GitHub Actions；本机不执行 `npm publish`。上传接受不等于已公开，Verify 超时不等于未上线或需要重新发布。
