# v0.27.1 — 空待审与差异栏残留修复

## 修复

- 净零判定与文本差异生成器统一使用逻辑行口径。仅 LF/CRLF/CR 或开头 BOM 不同不再计入待审；真实文本修改与末尾换行增删仍保留。
- 不改写原始快照或磁盘文件，不通过删除数据库或绕过跨端能力限制清理计数。
- 累计待审详情与工具栏统一路径身份解析，避免误回落到历史改动栏；已归档记录不再计入汇总及批量待审。
- 客户端对成功生成的空文本详情补充收敛路径，保留 Keep 能力、脏缓冲及批量忙状态守卫；非文本、失败或不一致详情不会自动结案。

## 验证

- 修复阶段定向回归：6 个文件、119/119 通过；类型检查、构建、diff check 通过。
- Web 实机：重启 Host 后 IslandSplash_ZDev2 的三个换行格式空待审变为 `pending: 0`、`items: []`，差异浮栏及底部入口消失。
- 三个游戏文件的 SHA256 与修复前一致，未执行 Keep/Undo、未删除审查记录。
- 发布三门结果以本次 Release Actions 为准。

## 升级说明与边界

包含 Host 逻辑修复，升级后需重启 DSH；仅刷新浏览器不足以加载新 Host 逻辑。
本次发布不自动安装到任何 profile；桌面版未部署或再次修改。
本次 GUI 验收针对所报空待审问题，不宣称覆盖所有跨端、主题、滚动、真实 apply_patch 或 Forge 场景；既有 v0.27.0 的其他未验证项继续保留。
