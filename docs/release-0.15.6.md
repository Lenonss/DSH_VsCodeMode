# dsh-vscode-mode 0.15.6

## 改动

- 资源管理器顶部 ↓ 改为调用插件自带 SVN 更新窗口，目标为当前项目根目录，不再只执行远端更新检查。
- SVN 变更页面顶部新增全局 ↓ 更新按钮，复用同一窗口；无需选中文件，也不依赖存在本地变更。既有只读远端检查与本地刷新保留。
- 非 SVN 项目、SVN 能力未知或 CLI 不可用时，不显示“正在读取本地 SVN 状态”等读取提示；能力丢失时立即清除提示，迟到的远端结果不恢复旧项目状态。
- 补充两个面板的真实组件元素树入口测试、CLI/窗口能力不可用测试及能力切换回归测试。mock 元素树测试不等于真实浏览器验收。

## 发布与验证边界

通过 tag v0.15.6 触发 GitHub Actions 发布，不执行本地 npm publish。无依赖或 peer 变更，锁文件不变。发布前顺序执行 npm run typecheck、npm run test（完整 JavaScript 发布套件及 nativeOpen）、npm run build，并核验打包入口；具体结果以发布记录为准。

当前会话缺少浏览器调试工具，真实 GUI 点击、主题、滚动及 Console 未验证。用户已明确接受此缺口；类型检查、单元测试与构建不代表 GUI 验收。本次不执行真实 SVN 更新。

## 更新提示

公开发布不等于当前 DSH 实例已安装或生效。本次不修改 profile、不安装、不重启 DSH，也不启动替代 GUI。正式更新后分别核验 Host/Client 运行版本，并刷新现有 GUI 验收。
