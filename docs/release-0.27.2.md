# v0.27.2：当前编辑文件 Tab 自动保持可见

## 改进

- 打开或切换文件后，所属编辑分组自动将活动 Tab 滚入顶部可见区域。
- 分屏、浮动编辑组独立定位；计划预览继续与文件共享同一条 Tab 栏。
- 关闭、固定、脏标记及编辑区宽度变化后重新检查。活动 Tab 已完整可见时不调整滚动。
- 只调整 Tab 栏的横向滚动，不调用 focus，不带动正文或外层页面；保留手动横滚。
- Tab 宽于可视区域时优先显示名称起始部分；卸载或更换选中目标时清理尺寸观察与待执行帧。

## 实现边界

使用同一视口坐标系计算裁切，替代原有 offsetLeft 与 scrollLeft 混合比较；将定位生命周期从工作台单条栏下沉至每个 EditorPane。不修改 Host、RPC、持久化格式、依赖或视觉样式。

## 验证与已知缺口

- 功能阶段类型检查通过，受影响 5 个测试文件共 113/113 通过，耗时 2.08 秒；本地构建通过。
- 发布前按批准流程另执行完整 JS 发布套件、类型检查和构建；最终结果见发布执行记录。
- 当前 GUI 未加载新 bundle，尚未完成真实交互、主题及 Console 验收；用户已明确接受该缺口，不以单测或构建代替 GUI 验收。
- 本次发布不自动安装插件、不修改 profile、不重启 DSH；当前运行实例是否生效须另行核验。

## 回滚

可安装上一稳定版 0.27.1 并按正常流程重新加载 DSH。公开版本及 tag 保持不可变，不覆盖发布历史。
