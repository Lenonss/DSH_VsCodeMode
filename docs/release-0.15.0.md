# v0.15.0：文件页签拖拽与多编辑组

## 功能

- 文件页签拖拽重排、跨组移动；拖到编辑区四边创建左右或上下分屏。
- 拖到页面允许的空白区域创建可移动、可调整大小的页面内浮窗，不是系统独立窗口；关闭浮窗将文件归回主编辑组。
- 拖入当前 DSH 对话输入框添加文件引用，保留源页签及已有草稿引用，不自动发送。
- 6px 拖拽阈值，Esc、窗口失焦和指针取消中止拖拽；无效落点不移动文件。
- 编辑缓冲、脏标记、保存版本守卫、视图状态及布局恢复随编辑组保留；最多8组。
- 落点矩面预览跟随主题，25% 不透明度、无描边；修复 DOMRect 非枚举属性导致的矩面丢失，拖动页签不选中文件名。
- 保留 v0.14.13 的资源管理器跟随活动文件功能。

## 发布边界

本版本基于远端 v0.14.13，未纳入开发工作区的其他兼容性诊断修改。依赖与 peer 未变，不重新生成锁文件。

用户已在当前 GUI 反馈并校正拖拽视觉效果；最终独立发布树未做自动真实浏览器/Console 冒烟，用户明确接受此验证缺口。类型检查、单测与构建不替代 GUI 验收。

发布走 GitHub tag/Actions；发布不表示已升级当前 DSH profile，不自动重启 DSH。

## 升级与回退

安装 `dsh-vscode-mode@0.15.0` 或 GitHub 同版本 tgz。回退可安装 `0.14.13`；多组布局由新版本独立键保存，旧版本不提供多组拖拽功能。升级或回退前保存未落盘编辑；具体 profile 以实际运行实例为准。
