# v0.14.13：资源管理器跟随活动文件

## 新增功能
- 打开或切换编辑文件时，资源管理器自动展开祖先目录，将对应文件滚入可见区域并高亮。
- 资源管理器隐藏或切到其他面板时不强制切换界面；切回后读取最新活动文件并定位。
- 目录懒加载较慢时等待树行提交，不再因短时重试窗口耗尽而丢失目标。
- 只调整资源树滚动，不抢编辑器键盘焦点；定位成功后普通重渲染不会反复拉回位置。
- 保留页签菜单的手动定位；目标更新、工作区切换和卸载使旧请求失效，并清理高亮计时器。

## 边界
工作区外文件、非法路径或尚不存在的树行不会误定位。目录失败沿用既有错误提示，后续刷新或重试可继续兑现目标。无新增配置、RPC、依赖或存储结构。

## 验证与升级
用户于 2026-10-14 确认本地功能验收通过。发布树与其他本地兼容性/MCP WIP隔离，包含定位函数和生命周期测试，并按项目发布流程执行类型检查、完整 JS 测试及双面构建。最终计数与发布实包证据见发布交付报告。

本次为客户端功能；已经使用开发目录联接的实例重建后强制刷新页面加载新客户端即可。正式安装用户更新到此版本后按 DSH 提示重新加载；不改变数据迁移规则，旧版本回退注意事项仍见历史发布说明。
