# v0.15.3：搜索结果强制刷新

## 功能

- 目标文件内容被改动后，工作区搜索面板不再保留过期匹配：内容变更事件（编辑器保存、外部磁盘改动或结构变更）会触发重跑当前查询，旧的匹配行与计数不会继续挂在面板上。
- 关键词与选项完全相同时重搜不再命中 60 秒结果缓存：`edrv.searchContent` 新增可选 `force` 标记，仅本次调用跳过缓存读取，仍以新结果写回缓存。
- 触发源覆盖两侧：内容型（`kind: text`）与结构型（`kind: structure`）刷新事件都重新搜索；刷新事件在 250ms 防抖窗口内合并，避免连续保存时重复拉起 ripgrep。
- 搜索面板同时订阅 `edrv:file-changed` 与 `edrv:refresh`，因此编辑器内保存（只发 `edrv:refresh`）与外部改动（由文件观察轮询发出 `edrv:file-changed`）都会刷新结果。

## 发布边界

本版本基于远端 v0.15.2，仅纳入上述搜索结果刷新修复；未纳入开发工作区中并行进行的编辑器布局/页签拖拽/SVN 冲突等在途改动。依赖与 peer 未变，不重新生成锁文件。

修复的源码与测试来自主工作区已验证的版本，逐字节复制到独立发布树；独立树内重新执行类型检查、完整测试套件与构建作为发布提交树的验证证据。真实 GUI 现场重测（打开面板→编辑目标文件→结果是否即时消失）尚未执行，用户如需现场确认应另行复测；类型检查、单测与构建不替代 GUI 验收。

发布走 GitHub tag/Actions；发布不表示已升级当前 DSH profile，不自动重启 DSH。

## 升级与回退

安装 `dsh-vscode-mode@0.15.3` 或 GitHub 同版本 tgz。回退可安装 `0.15.2`；本版本不改变持久化格式与副作用文件，回退不涉及数据迁移。升级后需重启 DSH Host 并强制刷新页面，仅刷新不会更新 Host；具体 profile 以实际运行实例为准。
