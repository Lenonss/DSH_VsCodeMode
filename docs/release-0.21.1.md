# v0.21.1 — 缺失历史文件的删除预览

作者：ddj · 2026-10-28

## 修复

- 历史待审文件在磁盘上不存在时，使用最后记录的完整快照，整文件按删除行展示，不再仅显示加载失败。
- Keep 保留删除状态并结清覆盖的待审记录，不写磁盘。
- Undo 恢复所展示的完整快照，通过 createIfAbsent 创建；不会用局部差异拼接文件或覆盖重新出现的文件。
- 删除预览只读，保存入口不会意外重建文件。单文件与 Keep All / Undo All 均按整文件删除语义处理。
- 记录变化、文件重现、缺少完整快照或写入失败时停止操作；稳定操作 ID 防止重复请求再次写文件。

## 验证与边界

发布前执行类型检查、完整 JavaScript 发布测试套件及 Host/Client 构建，实际结果见发布报告与 CI。
定向回归覆盖完整快照恢复、CRLF 展示、删除行号、重复请求、文件重现、记录变化与批量预检。

本次真实 GUI 验收尚未执行，已获用户明确接受该缺口；单测和 mock DOM 不代替浏览器验收。
没有可靠完整快照时仍会报告缺少证据，不凭空拼接内容。
发布不自动安装到当前 DSH profile，也不自动重启。安装新版本后须重启 DSH 并刷新页面才能加载新的 Host/Client。
