# dsh-vscode-mode 0.15.5

## 改动

- 保留 0.15.4 的共享 SVN 非模态浮窗、独立文件对比与来源任务返回逻辑。
- 浮窗拖动/缩放使用 rAF 直接更新几何，手势结束才提交一次状态；多个窗口共享一个 viewport resize 监听，并按帧合并视口调整。
- SVN 日志行表与单行 memo，选中 revision 使用 Set，稳定行回调身份；窗格高度同值不重复提交。当前「显示全部」仍可能渲染 5000 行，未做列表窗口化。
- LSP 编辑通知改传惰性文本函数，250ms 去抖实际发送前才读取全文；model 已销毁导致取值抛错时放弃该次同步，不以空文本覆盖服务器文档。协议仍使用全文同步。
- 外部文件打开心跳：页面可见时仍为 3 秒，隐藏时每 5 拍一次（约 15 秒）；保留心跳以维持宿主 30 秒租约。这是定时器目标周期，不承诺后台浏览器实际调度时刻。
- SVN 冲突状态只读查询按每批 4 个并发执行，结果保序，不并发执行 SVN 写操作。
- 客户端兼容性摘要结合实际安装能力、DSH 版本与用户选择，仅显示适用诊断；保留真正缺失或明确选择的旧版能力告警，不修改文件打开路由。
- 补充工作区搜索在内容变化后强制刷新、通知合并、作用域隔离与卸载清理回归测试；刷新机制沿用已发布的 0.15.3 实现。
- 编辑器工作台与拖拽预览 portal 改为 Fragment；保留工作台自身作用域和全局拖拽样式。

## 发布与验证边界

本版通过 tag v0.15.5 触发 GitHub Actions 构建与 npm 发布，不执行本地 npm publish。依赖与锁文件不变。发布过程按 npm run typecheck → npm run test → npm run build 顺序执行，并检查打包双入口；具体结果以发布记录为准。

当前会话无法进行真实浏览器 DOM/Console 验证。用户已明确接受本次 GUI 验证缺口：受影响入口、拖动/缩放、兼容性页、搜索焦点、LSP、主题及滚动未在本次发布会话现场重测。编译、单测与 mock 不代表实际 GUI 验收。既有性能阶段验收记录不扩大为全部功能验收。

## 更新提示

公开发布不等于安装或当前 DSH 实例生效。本次不改 profile、不安装插件、不重启 DSH。正式安装更新后需重启目标 Host，并对现有 GUI 硬刷新；Host 与客户端运行版本应分别核验。开发链接形态下构建更新磁盘产物，仍不代表运行中的 Host 已加载新代码。

本版不宣称修复资源管理器“目录不存在”提示，也未实施 EditorView 打字期状态优化、Monaco 预热策略修改、minify、MCP 启动异步化或 archiveDb 同步策略变更。
